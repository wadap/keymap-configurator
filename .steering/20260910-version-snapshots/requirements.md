# バージョン保存

ユーザー承認済みの機能: 名前付き保存、現在との差分表示、保存版への復元、適用前の自動保存。指定された Firebase project は keymap-configurator。Googleログイン＋Firestoreを利用する。

対象は物理配置と全レイヤーのキーマップ。マクロ・コンボの内容は対象外。通常キーの編集範囲は維持し、保存に含まれる高度なキーコードは損失なく保持する。実機への書き込みはユーザーが適用を押した時だけ。検証では実機の設定を変更しない。

ログイン後は本人だけが読める保存版をクラウドに追記。未ログインでも既存編集は使え、適用前の復旧用保存はブラウザに残す。クラウド保存成功はサーバー応答後のみ表示する。
