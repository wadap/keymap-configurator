# 最小版の要求

設計メモ v0.1 を参考資料として、最初の実機検証ができる構成を実装する。

- Chrome / Edge の WebHID から Vial 対応キーボードに接続する。
- 機器内の定義、全レイヤーの生の16bitキーコードを読み、物理位置に表示する。
- 通常キー・修飾キーを1キーずつ変更し、差分の明示的な適用とUndoを行う。
- 適用前に全キーマップと機器IDをブラウザに保存し、変更対象だけを書き、読戻しで検証する。
- 実機と明確に区別したサンプルで一連の操作を試せる。
- AI、レイヤーアクションの編集、Macro / Combo / Tap Dance の編集・読取UIは次段階。全設定のバックアップとは称さない。

完了の区別: 自動テストとビルド、ローカル起動まで実施する。実機への書込はユーザーが接続して操作する受入試験であり、ここでは実施・成功と称さない。
